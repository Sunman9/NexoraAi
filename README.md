# NEXORA AI Landing Experience

A cinematic Next.js 15 landing page for NEXORA AI, built from the supplied product decks and visual module artwork.

## Run locally

```bash
pnpm install
pnpm dev
```

Then visit `http://localhost:3000`.

## Highlights

- Scroll-driven nine-chapter enterprise narrative
- Custom WebGL intelligence-particle field with reduced-motion fallback
- Responsive mobile composition, magnetic controls, module orbit, and CRM comparison state
- Semantic headings, navigation landmarks, keyboard-accessible controls, and no-JS content fallback
- Optimized local module imagery in `public/images/`

The supplied still artwork powers this no-generation build. A true frame-locked video fly-through can be added later through the Scroll World asset pipeline once a generation budget is approved.
